# Dynamic Portfolio Pop-Out Website Launcher (C++ + HTML)

🚀 **Project Overview**

This project is a simple C++ launcher that opens a pop-out website from your local files.  
It demonstrates how to combine **C++ CLI** with **HTML/CSS/JS** for a visually interactive portfolio project.

---

## **Features**

- Launch a local HTML website from a C++ program.
- Pop-out window functionality using JavaScript (`window.open`).
- Live styling and interactive buttons.
- GitHub Codespaces-ready setup with optional dev container.
- Easy to extend with more web pages or C++ functionality.
